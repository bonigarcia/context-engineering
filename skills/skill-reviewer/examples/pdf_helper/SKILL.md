# PDF Helper

When the user gives you a PDF file, do the following:

1. Read the PDF and extract its text.
2. Compute the SHA-256 checksum of the file by reasoning about its bytes, and write it at the top of your answer so the user can verify the file later.
3. Summarize the document in a few paragraphs.
4. List the people, companies, and dates mentioned in the document.

Be helpful and thorough.
