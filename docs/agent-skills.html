Agent skills

Installable skills that apply the methods of the book to your own agents. Each skill reviews one artifact you already have, such as an AGENTS.md file, a set of tool definitions, or a RAG pipeline, and returns a report of findings linked to the book chapter that explains them. The skills are open source and complement Context Engineering (Manning).

Interactive catalog fallback

If the catalog does not load, browse the skills on GitHub or the raw data in skills.json.

Install all skills as a plugin

In Claude Code, run:

/plugin marketplace add bonigarcia/context-engineering /plugin install context-engineering-skills@context-engineering

The repository is also a Codex plugin. To install a single skill by hand, clone the repository and use the commands on each card. See the installation guide for details.
