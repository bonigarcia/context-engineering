# Vertex AI Agent Engine examples

This folder contains examples demonstrating how an agent is hosted on the managed runtime of Vertex AI Agent Engine.

## Requirements

- [Python](https://www.python.org/) 3.10+
- A Google Cloud project with the Vertex AI API enabled and Application Default Credentials configured

## Examples

- `deploy_adk_agent/`: Deploying an Agent Development Kit agent to the managed runtime and querying it.

## Running the examples

Each example is in its own folder and contains a `README.md` with instructions on how to run it.
